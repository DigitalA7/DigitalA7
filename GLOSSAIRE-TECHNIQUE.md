# Glossaire technique

- **AIR** : représentation algébrique d’une trace d’exécution utilisée par certains systèmes STARK.
- **Witness** : valeurs privées qui complètent les entrées publiques pour satisfaire les contraintes.
- **FRI** : protocole de vérification de faible degré utilisé dans plusieurs constructions STARK.
- **Circuit** : relation arithmétique qui exprime la propriété à prouver.
- **Sous-contrainte** : situation où une valeur ou une condition importante n’est pas suffisamment reliée au circuit.
- **Bootstrapping** : opération FHE qui réduit le bruit accumulé afin de poursuivre le calcul.
- **Paymaster** : composant pouvant prendre en charge les frais d’une transaction selon des règles données.
- **Nonce** : valeur ordonnant une action et contribuant à empêcher sa réutilisation.
- **Finalité** : niveau de certitude qu’un état ne sera plus réorganisé.

## Usage

Ce glossaire sert de point d’entrée. Chaque terme doit ensuite être replacé dans le code, le protocole et son modèle de confiance.
