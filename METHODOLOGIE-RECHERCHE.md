# Méthodologie de recherche

## Partir des sources

Identifier le dépôt, la branche, la révision et les fichiers centraux avant de formuler une conclusion. Relier les affirmations importantes au code ou à une documentation officielle.

## Décrire les mécanismes

Suivre les données, les invariants, les acteurs et les frontières de confiance. Séparer fait observé, interprétation, hypothèse et résultat effectivement testé.

## Garder le périmètre visible

Une lecture documentaire ne vaut ni audit, ni benchmark, ni garantie de production. Les limites et questions ouvertes doivent rester explicites.
